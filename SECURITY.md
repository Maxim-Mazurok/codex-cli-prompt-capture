# Security Policy

## Reporting

Please report vulnerabilities privately through the repository host's security-advisory feature. Do not include captured requests, prompts, source code, credentials, personal data, or other sensitive material in a public issue.

## Scope

The Codex capture server is intended to bind only to `127.0.0.1` and must remain capture-only. Reports about unintended network exposure, forwarding, credential persistence, or ineffective redaction are in scope.
